# Домашнее задание по DevOps: Скрипт для погоды


Этот проект содержит Bash-скрипт для получения текущей погоды в любом городе через терминал.

## 🚀 Возможности

*   Получение температуры и краткого описания погоды для любого города.
*   Использование бесплатного и открытого сервиса `wttr.in` — **без необходимости в API-ключе**.
*   Простой запуск одной командой.

## ⚙️ Требования

*   **ОС:** Linux, macOS или WSL (Windows).
*   **Утилиты:** `curl` (для отправки запросов к сервису погоды).
