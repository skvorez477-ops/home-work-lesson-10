# Домашнее задание по DevOps: Скрипт для погоды

Этот проект содержит Bash-скрипт для получения текущей погоды в любом городе через терминал. Скрипт был создан в рамках обучения на курсе DevOps в Месяце 1.

## 🚀 Возможности

*   Получение температуры и описания погоды для любого города.
*   Использование публичного API OpenWeatherMap.
*   Простой запуск одной командой.

## ⚙️ Требования

*   **ОС:** Linux, macOS или WSL (Windows).
*   **Утилиты:** `curl` (для отправки запросов к API).
*   **API-ключ:** Бесплатный ключ от [OpenWeatherMap](https://openweathermap.org/api).
